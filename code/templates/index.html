🎯 Why Class Weighting Matters

Problem: CT scans have extreme class imbalance - 97.7% background (non-liver), 2.3% liver tissue.

Unweighted Model: Achieved 99% accuracy but only 24% recall. The model learned to predict "not liver" for almost everything because that maximizes accuracy. This is useless for medical imaging!

Weighted Model (Our Solution): Assign weight ratio of 44:1 to liver vs background. This forces the model to pay attention to the minority class (liver) during training. Result: 71% recall while maintaining 99% specificity.

Impact: In a 1000-pixel image with 50 liver pixels, unweighted finds 12 pixels (missed 38). Weighted finds 35+ pixels (missed 15). Critical difference for diagnosis!
